## BonusBoxes

## About the Project

<sup align = "left"> 
   *Status: The project is currently not deployed*
</sup>

This project was developed to display data from the x-kom mobile application. The backend of the project is implemented using FastAPI and MongoDB. The frontend is built with React. The website allows for the display offers along with their expiration time and a countdown timer. Once an offer expires, it is deactivated, and after a few days, it is removed from the database.

Data for this application is provided by a separate script (currently in a private repository) that runs on a Raspberry Pi 4 and utilizes Python and Appium for Android automation. Thanks to the optimized automation script, it is capable of managing hundreds of accounts daily.
